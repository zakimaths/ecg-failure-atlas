Detector method and replay

Rate estimates are 60,000 divided by the median candidate interval in milliseconds over [1, 7) seconds.

Detector input is rounded to 0.000001 mV for reproducible integer arithmetic; the recorded and processed waveform exports are unchanged. This original slope-energy detector smooths over 11 samples, measures a 10-sample difference, then averages squared differences over 81 samples. Both branches use a threshold derived from the recorded input. Candidate locations are refined to the largest absolute deviation from a 201-sample moving baseline within ±80 ms; that deflection can be an R or S wave. It is not a clinically validated R-peak detector.

Pairs maximise the number of matches, then minimise total absolute timing difference after subtracting the declared FIR delay. Raw and adjusted shifts are both retained. The six-second analysis window can leave candidates unmatched near its boundaries.

uv run --locked ecg-atlas replay-beats detection.json

JSON includes the source waveform analysis, detector settings, candidate indices, pairing results and score arrays. Python repeats the source processing and independently checks detection. The existing PTB subset has no beat annotations included, so this comparison does not report sensitivity, precision or diagnostic accuracy.

Sweep method and replay

Each recorded lead uses its own threshold, derived from its unprocessed score. That threshold stays fixed across cutoffs. Matching removes the declared FIR delay and uses the selected tolerance. Timing and rate maps show absolute magnitudes; signed values remain in the exports. Both branches use [1, 7) seconds. N/A means no matched pair for timing, or fewer than two candidates in either branch for rate change.

The subset contains three subjects. Leads are related measurements, not independent subjects. The colour scale describes this run and does not indicate clinical quality. JSON stores source checksums, settings, filters, candidate locations, matches and rates. Replay reloads the pinned samples and recomputes every row.

DATA PROVENANCE

PTB Diagnostic ECG Database v1.0.0

Contains information from the PTB Diagnostic ECG Database, made available under the ODC Attribution License v1.0. Collected by Michael Oeff at University Clinic Benjamin Franklin, Berlin; provided by PTB through PhysioNet.

Selection: the first listed record from each of the first three subject directories, using the first eight seconds of the 12 standard leads. This convenience subset is not a representative cohort. Original digital counts are retained without resampling, normalisation or denoising. Clinical header comments are omitted.
