SEPARATE THE EFFECTS

A smoother line can still be a less faithful signal

Run the same clipping and filtering on the clean reference. That branch measures the change introduced by processing alone. The difference between the two processed branches measures the effect of the added corruption through the pipeline.

How the error components add up

Let d = processed clean − reference and e = processed corrupted − processed clean. The total error is exactly d + e. Squared errors include a cross term, so the two component RMS values cannot simply be added.

This is an algebraic decomposition on these samples. With clipping, the effect of corruption is nonlinear. A different seed or reference can change the result.

REPRODUCE THE RESULT

Keep the samples, not just the picture

The experiment file includes every sample, all settings, FIR coefficients, the analysis window and measurements. A shared link carries the settings; it recalculates the result when opened.

Replay a saved experiment

Choose an experiment JSON from this page. The browser regenerates the reference and noise, reruns the pipeline, and compares all arrays, coefficients and measurements. A changed result is rejected. Nothing is uploaded.

Check it independently in Python

From the repository, install the locked environment. Both modes check the saved numerical results within a 1e-10 absolute/relative tolerance. Saved-input mode uses the stored input samples; regeneration also recreates the reference and seeded noise.

uv sync --locked
uv run --locked ecg-atlas replay-live experiment.json --mode saved-input
uv run --locked ecg-atlas replay-live experiment.json --mode regenerate

The browser uses direct convolution and a windowed-sinc filter. Python checks it with NumPy and SciPy. Zero samples are assumed outside the record. Centered filtering uses future samples and is an offline comparison, not real-time processing.

These synthetic samples are not patient data or a physiological simulation. This page tests engineering behaviour, not diagnostic performance.
