Methods and local replay +

The reference signals

The ECG-like waveform is an original sum of Gaussian components. It is deliberately simplified. The aliasing experiment uses a pure sine. These reference experiments use synthetic samples. The hospital analysis page uses a separately attributed PTB recording subset.

Comparison method

The gallery displays saved samples. You can also recalculate from the saved input or regenerate the reference and rerun the recipe. File hashes identify changes to the bundle. Numerical replay compares arrays and measurements within declared tolerances.

Metrics use full-resolution data. Zooming does not change them. Each array records its sample rate and time origin. Lines connect discrete samples for readability.

Local numerical replay

Install the repository's locked dependencies and run its tests. Extract a downloaded case into a new folder, then run:

uv run --locked ecg-atlas verify CASE_FOLDER
uv run --locked ecg-atlas replay CASE_FOLDER --mode saved-input
uv run --locked ecg-atlas replay CASE_FOLDER --mode regenerate

The manifest records transformation order, coefficients, boundary settings and array metadata.
